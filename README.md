# Prospecta

*Bilateral LLM-mediated retrieval: both sides of a memory exchange are shaped by an LLM — the writer answers anticipated questions, the reader poses real ones, and a hybrid index over Postgres+pgvector matches them in question-form.*

This is v0.1 development. See `docs/design/prospecta/plan-v2.md` for the implementation plan; see `PRINCIPLES.md` for the 15 load-bearing principles that govern this library.
